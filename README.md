# Twirling Star Web Services — Developer Portfolio

This is my first full coding project and the foundation of Twirling Star Web Services.  
I built this portfolio completely from scratch using HTML, CSS, and JavaScript — no frameworks, no generators — to reflect my real skill set and the warm gold + ivory aesthetic that defines my brand.

## ✨ Features
- Fully custom multi‑page website  
- Template store with cart + PayPal checkout  
- LocalStorage‑based cart system  
- Custom brand identity + seal  
- Clean, beginner‑friendly code  
- Mobile‑responsive layout  

## 🎨 Design Philosophy
My goal was to create a portfolio that feels warm, approachable, and intentional.  
The design blends:
- soft gold accents  
- ivory backgrounds  
- subtle fantasy “holy‑kingdom” influences  
- clean, readable layouts  

Everything is hand‑coded to reflect my actual abilities and growth as a developer.

## 🛠️ Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Vanilla)**  
- **PayPal Smart Buttons**  
- **LocalStorage**
